# Ivy & Oak — Avance N°1 (React + Vite + Tailwind CSS)

## Ejecutar
```bash
npm install
npm run dev
```
Abre http://localhost:5173

## Build
```bash
npm run build
```

## Estructura
- `src/components/`: Header, Navbar (responsive), Hero, About, Catalog, ProductCard, SizeGuide, ReservationForm, Footer
- `src/data/products.js`: productos, guía de tallas y enlaces del menú
- Tailwind v4 con tokens de color y tipografía en `src/index.css` (`@theme`)
